# Documento de Vision V1

## 1. Proposito

Desarrollar un sistema web para automatizar el registro y control de asistencia de los trabajadores.

## 2. Problema

Actualmente, los encargados del control de asistencias suelen tener errores con los registros y entre otras problematicas como largas filas de espera y dificultades para consultar la informacion historica.

## 3. Alcance

Incluye: Registro personal del trabajador por medio de la web, generacion y control de reportes para los administrador autorizados.
No incluye: Gestion de nomina del trabajador, soporte tecnico para el trabajador, informacion de la empresa.

## 4. Interesados

|Rol | Necesidad|
| - | - |
|Trabajador| Registrar su asistencia indenpendientemente|
| Administrador| Contro de reportes|

## 5. Objetos medibles

- Reducir un 70% los errores de los registros manuales que provocan inconsitencias en la base de datos.
- Eliminar las largas filas de espera para el registro de asistencia

## 6. Requisitos de alto nivel

- REQ-001: Registrar trabajador en el sistema.
- REQ-002: Registrar entrada y salida de asistencia.
- REQ-003: Generar reportes

## 7. Restricciones
- Primera version en 7 semanas
- Debe correr en el navegador.
