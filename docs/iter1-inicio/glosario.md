| Sistema | Aplicación web de Dasyar que automatiza la marcación y el control de asistencia. Funciona en PC, tablet y celular | Aplicación, App, Plataforma, Software, Herramienta |
| Trabajador | Persona que labora en Dasyar y marca su propia asistencia con su DNI| Empleado, Operario, Colaborador, Personal, Usuario|
| Administrador | Persona autorizada de Dasyar que entra con contraseña para gestionar trabajadores, configurar, consultar, corregir y exportar | Encargado, Supervisor, Admin, Jefe, RR. HH., Usuario |
| DNI | Documento Nacional de Identidad de 8 dígitos. Es lo único que el Trabajador escribe para marcar | Código, ID, Documento, Cédula, Clave de marcación |
| Marcación | Registro crudo de que un Trabajador ingresó su DNI. Guarda fecha y hora| Fichaje, Check-in, Picada, Marca |
| Entrada | Marcación con la que el Trabajador empieza un turno. La primera del turno | Ingreso, Check-in, Llegada |
| Salida | Marcación con la que el Trabajador termina un turno. Se registra cuando ya existe la entrada | Egreso, Check-out, Retiro |
| Activo / Inactivo | Estado de un Trabajador que puede o no marcar | Dado de baja, Eliminado, Deshabilitado, Cesado |
| Asistencia | Resultado calculado de un día de un Trabajador: fecha, estado, minutos de tardanza. Se obtiene a partir de las Marcaciones | Registro, Presencia, Parte diario, Planilla |
| Turno | Franja fija de trabajo. Hay dos: Mañana (7:00 a 12:30) y Tarde (14:00 a 19:00). Cada Trabajador tiene uno o dos | Horario, Jornada, Franja, Slot, Agenda |
