# SRS - Sistema de asistencia DASYAR (v1.1)
Línea base de requesitos al inicio de la Fase de Elaboración. Los IDs se mantienen desde la interación 1.

| ID | Requisito |
|---|---|
| REQ-001 | El sistema debe permitir registrar a un trabajador. |
| REQ-002 | El sistema debe permitir registrar la entrada y la salida de un trabajador. |
| REQ-003 | El sistema debe permitir generar reportes de asistencia. |
| REQ-004 | El sistema debe permitir autenticar al administrador. |
| REQ-005 | El sistema debe permitir configurar turnos y una tolerancia de entrada de hasta 15 minutos como máximo |
| REQ-006 | El sistema debe permitir corregir la asistencia indicando un motivo. |
| REQ-007 | El sistema debe permitir al administrador cambiar su contraseña. |
| REQ-008 | El sistema debe calcular las faltas y las horas extras. |
